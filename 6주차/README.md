## 단축 URL 시스템 - 기능적 요구사항

### 기본 요구사항

1. **사용자는 긴 URL을 입력하여 짧은 URL을 생성할 수 있어야 한다**
    - 하루 평균 **1억 개의 URL 생성**
2. **생성된 단축 URL로 접속 시 원본 URL로 리다이렉트되어야 한다**
    - Read : Write 비율 = **10:1**
3. **단축 URL은 고유해야 하며 충돌이 발생하지 않아야 한다**
    - 단축 키 길이: **7자리** (62^7 = 약 3.5조 개 조합 가능)
4. **단축 URL은 최소 5년간 유효해야 한다**
5. **(선택) 사용자 정의 단축 URL을 지원할 수 있다**
    - 예: `short.ly/my-custom-link`
6. **(선택) 단축 URL의 접속 통계를 제공한다**
    - 클릭 수, 지역, 디바이스 정보 등

## 비기능적 요구사항

- **단축 URL 생성은 1초 이내에 완료되어야 한다**
- **리다이렉트 응답 시간은 100ms 이하여야 한다** (캐시 히트 시 50ms 이하)
- **시스템은 99.99% 가용성을 보장해야 한다** (연간 다운타임 52분 이하)
- **단축 URL은 예측 불가능해야 한다** (보안상 중요)
- **동일한 원본 URL에 대한 처리 정책이 명확해야 한다** (매번 새로 생성 vs 기존 것 재사용)
- **대규모 트래픽 스파이크를 처리할 수 있어야 한다** (예: 바이럴 링크)
